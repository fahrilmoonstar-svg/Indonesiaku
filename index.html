◆ 02 — SEKILAS KODE

Kelas, Warisan & Error Handling

Sintaks yang konsisten dan mudah dipahami.

  • 1 Gunakan init sebagai konstruktor kelas.
  • 2 Pewarisan memakai tanda <.
  • 3 Penanganan error dengan coba/kecuali dan naikkan.
kelas.idk 
kelas Hewan {
    init(nama, suara) {
        diri.nama = nama
        diri.suara = suara
    }

    bersuara() {
        cetak(
            diri.nama, "berkata:",
            diri.suara
        )
    }
}

# Pewarisan dan konstruktor turunan
kelas Anjing < Hewan {
    init(nama) {
        super.init(nama, "Guk")
    }
}

coba {
    Anjing("Rex").bersuara()
} kecuali e {
    cetak("gagal:", e)
}
